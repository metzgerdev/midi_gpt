Numbers on the keys are token ids, not MIDI numbers; each octave band carries its MIDI range and the token ids that cover it. Black and white keys are drawn as a keyboard for legibility only — the model sees 61 undifferentiated ids. wt is the class weight the training loss applies to that group.

Pitch ids are contiguous, so the arithmetic is a single offset in both directions. Anything outside 24–84 is clamped into range when the corpus is built.

Sampling constraints

  • BOSOpens the sequence and never recurs. Masked out of the logits at every step, so it can be fed in but never sampled.
  • SUSTAINExtends the note before it, so it is illegal at step 0 and illegal after a rest — there is nothing to hold.
  • EOSEnds the clip. Sampling stops the moment it appears.

Both rules are enforced on the logits rather than learned. An unmasked stray sustain is silently discarded when tokens are converted back to notes, which quietly shortens the clip the model thought it was writing.
