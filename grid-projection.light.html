Midi GPT · grid_proj

How rhythm becomes a vector

The simplest of the three conditioning paths, and the strangest. It is a Linear(1, 128) fed one binary number per step — so however many parameters it holds, it can only ever produce two different vectors.

1 · input
0.0 or 1.0
One scalar for this sixteenth: is a drum struck here?
2 · operation
w·x + b
A single 128-d direction scaled by x, plus a bias.
3 · output
128 floats
Becomes grid_proj in the input sum.

Two parameter vectors, two possible outputs

256 parameters in total: one 128-d weight and one 128-d bias.

w ‖w‖ = 4.70
b the bias
x = 0 = b
no onset
x = 1 = w + b
onset here

Because the grid is binary at training (attack flags from note_onsets) and binarised again at inference (> 0.25 on the kick envelope), no other value of x is ever presented. The layer is a two-entry lookup table wearing a linear layer's clothes — and the two entries sit 4.70 apart in the 128-d space.

What x actually looks like

The kick grid of each shipped drum loop, one cell per sixteenth, bar lines every 16. Every lit step gets w + b; every dark step gets b.

house · four-on-the-floor26/64 onsets
uk garage · two-step20/64 onsets

Both patterns visibly repeat at the halfway point: the loop is analysed over two bars and tiled to fill four, so bars 3 and 4 always restate bars 1 and 2. In training the grid was the stem's own note-ons across all four bars and was free to develop — about a third of the corpus does.

All three are learned, and all three land in the same 128-d space to be summed. They differ only in how much they can say.

Why bother with a linear layer

A two-state signal could have been an nn.Embedding(2, 128) and behaved identically. The Linear form costs nothing extra and leaves the door open: feed it a continuous value and it interpolates along w, which would let kick velocity condition the model rather than a bare flag.

That option is currently unused. onset_grid does return a normalised envelope with real dynamics in it, but make_track thresholds it to 0/1 before the model sees it — so the expressive range the layer can represent is discarded one line upstream.
